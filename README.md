# Waheed Rafiq Developer Profile — React TypeScript Model

This is a React + TypeScript/Vite rebuild of the public content from `https://waheedrafiq.github.io/`.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL that Vite prints in the terminal, usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- The project uses remote image URLs from the current GitHub Pages site for the logo and focus group image.
- The public website contained a password note for protected downloadable files. That was intentionally not copied into this React model for safer sharing.
- This is a modern single-page model of the existing website rather than a pixel-perfect clone.
